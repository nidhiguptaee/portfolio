# Nidhi Gupta – Portfolio

**Hardware Engineer | AI/ML | Python**

A personal portfolio website showcasing education, work experience, and technical skills.

## Features

- **Hero section** – name, animated role titles, and social links
- **About** – brief bio with key highlights and summary stats
- **Education** – degree history with institutions, years, and relevant coursework tags
- **Experience** – work history with role details, achievements, and technology tags
- **Skills** – categorised skill bars for Hardware/RTL, AI/ML, Software, and Embedded Systems
- **Contact** – contact info cards and a client-side contact form

## Tech Stack

Plain HTML5, CSS3, and vanilla JavaScript – no build tools or frameworks required.

## Getting Started

Open `index.html` directly in any modern browser, or serve the directory with any static file server:

```bash
npx serve .
# then visit http://localhost:3000
```
